# Testing rules

Pick the test-writing skill matching this project's actual stack before writing or changing any test.

| Rule | Detail |
|---|---|
| Match skill to tech | Use the skill matching the current stack. No matching skill exists → propose creating one, based on an existing skill as a template or from scratch. |
| Tech is a fact | The stack is defined in `specs/02-tech.md` — check it, don't guess, don't duplicate it here. |
